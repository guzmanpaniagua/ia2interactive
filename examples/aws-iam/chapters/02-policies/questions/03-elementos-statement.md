## Selecciona los elementos obligatorios de un Statement en una política

- [x] Effect
- [x] Action
- [x] Resource
- [ ] Condition
- [ ] Principal en políticas de identidad

> **Explicación:** Effect, Action y Resource son elementos obligatorios en un Statement. Condition es opcional, y Principal solo es necesario en políticas basadas en recursos.
