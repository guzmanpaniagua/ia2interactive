## Selecciona todas las buenas prácticas de seguridad en IAM

- [x] Activar MFA en todos los usuarios con acceso a la consola
- [x] Usar roles de instancia en EC2 en lugar de access keys
- [ ] Compartir credenciales entre compañeros del mismo equipo
- [x] Rotar las access keys regularmente
- [ ] Desactivar CloudTrail para mejorar el rendimiento
- [x] Seguir el principio de mínimo privilegio

> **Explicación:** Las buenas prácticas incluyen MFA, roles de instancia, rotación de keys y mínimo privilegio. Nunca se deben compartir credenciales ni desactivar CloudTrail.
