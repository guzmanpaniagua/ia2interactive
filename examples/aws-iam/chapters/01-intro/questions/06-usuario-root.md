## ¿Qué características tiene el usuario root de AWS?

- [x] Tiene acceso completo a todos los recursos y servicios de la cuenta de AWS. Se crea automáticamente al abrir la cuenta y no se puede eliminar. Se recomienda no usarlo para tareas diarias y protegerlo con MFA.

> **Explicación:** El usuario root es la identidad con máximos privilegios en la cuenta. Por seguridad, se debe crear un usuario IAM con permisos de administrador para las tareas cotidianas.
