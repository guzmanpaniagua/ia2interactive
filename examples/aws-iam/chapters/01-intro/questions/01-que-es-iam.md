## ¿Qué es AWS IAM?

- [ ] Un servicio de almacenamiento de archivos
- [x] Un servicio para controlar el acceso a recursos de AWS
- [ ] Un servicio de bases de datos
- [ ] Un servicio de computación en la nube

> **Explicación:** IAM (Identity and Access Management) es el servicio de AWS que permite gestionar de forma segura el acceso a los recursos de tu cuenta.
